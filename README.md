## 🏎️ Sobre o projeto

**Pit Wall** é um projeto acadêmico desenvolvido para recriar uma página temática do **Grande Prêmio de São Paulo**, realizado no Autódromo de Interlagos.

A proposta é colocar em prática os conhecimentos de **HTML5 e CSS3**, construindo uma página inspirada no universo da Fórmula 1, com identidade visual esportiva, organização de conteúdo e adaptação para diferentes tamanhos de tela.

O desafio é desenvolver a interface utilizando apenas HTML e CSS, explorando recursos modernos de estilização e estruturação.

## 🏁 O que a página apresenta

- **Hero de destaque:** área principal com identidade visual inspirada no GP de São Paulo.
- **Cards de pilotos:** apresentação dos competidores em uma grade responsiva.
- **Filtros:** organização visual para navegar pelas informações.
- **Ingressos:** formulário estruturado para simular a seleção de ingressos.
- **Classificação:** tabela com cabeçalho e informações organizadas.
- **Visual de corrida:** cores, imagens e elementos gráficos inspirados no automobilismo.

## 🧰 Tecnologias e recursos

| Tecnologia / Recurso | Aplicação no projeto |
|:---|:---|
| **HTML5** | Estruturação semântica da página |
| **CSS3** | Estilização, cores, espaçamentos e layout |
| **:root** | Variáveis para definir a paleta de cores |
| **Flexbox** | Alinhamento do topo, hero e filtros |
| **CSS Grid** | Organização dos cards de pilotos |
| **Form Grid** | Distribuição dos campos do formulário |
| **Tabela HTML** | Exibição da classificação com `thead` e `tbody` |
| **Media Queries** | Adaptação para dispositivos móveis |
| **Google Fonts** | Tipografia personalizada |
| **Background Image** | Imagem de fundo para compor o visual |
| **CSS** | Elementos visuais inspirados na zebra da pista |

## 📱 Responsividade

A página foi pensada para oferecer uma experiência organizada em diferentes dispositivos:

- 💻 **Desktop:** aproveitamento do espaço horizontal e apresentação completa das seções.
- 📱 **Mobile:** reorganização dos elementos para telas menores, mantendo a leitura e a navegação confortáveis.

## 🎯 Objetivo da atividade

Praticar a construção de interfaces web utilizando HTML e CSS, trabalhando principalmente:

- Estruturação de conteúdo com HTML;
- Organização de layouts com Flexbox e Grid;
- Criação de identidade visual com variáveis CSS;
- Estilização de formulários e tabelas;
- Responsividade com Media Queries;
- Uso de imagens e fontes externas.
